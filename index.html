📇 سجل بطاقة الجمعية

كل مرة تصيفطي فيها بطاقة الجمعية لولي أمر، كيتسجل هنا تلقائيا (الاسم + الهاتف + التاريخ + الوقت) وكيتصيفط للسحابة (Firebase/Supabase/Appwrite/Sheet) — دليل باقي محفوظ حتى بعد حذف الطالب أو تبديل الهاتف
تأكيدات التوصل/القراية مخفية بالضبط — خاصك الكود السري باش تبان
مسح السجل من هاد الجهاز باش ماتعمرش الذاكرة (النسخ فالسحابة كتبقى، تقدر تسترجعها من "استرجاع شامل")
استرجاع شامل: كيجمع السجل من Firebase + Supabase + Appwrite + Google Sheet مرة وحدة، ويدمجه مع اللي عندك محليا (بلا مسح)
صيفط السجل بالإيميل (Gmail كيسجل تاريخ الإرسال بشكل مستقل عن التطبيق — دليل زيادة)
تحميل السجل كملف نصي (تقدري تحتفظي بيه فالهاتف كدليل خارج التطبيق)

🔥 تسجيل الدخول بـ Google (اختياري — Drive و Sheet غير)

ماداخلش بعد (ماشي ضروري)
Firebase و Supabase و Telegram خدامين بلا هاد الزر خالص. الزر هادا خاصك بيه غير إيلا بغيتي زيادة Google Drive و Google Sheet (هادوك زوج وحدين لي محتاجين Google بحكم القانون ديال Google نفسها)
رجّع البيانات ديالك من Firebase — بلا Gmail، خدام دائما بمساحة موحدة
استرجاع شامل: كيجمع فنفس الوقت من Firebase + Supabase + Appwrite + Drive + Sheet + Telegram + GitHub + Dropbox
صيفط نسخة دابا لـ Firebase

🟢 نسخة احتياطية Supabase (ضمانة رابعة)

خاصك تكون داخل بـ Google (فقسم Firebase فوق) — كل حساب عندو بياناته الخاصة، بلا تخلط مع حتى واحد
صيفط نسخة دابا لـ Supabase
رجّع آخر نسخة من Supabase — كيدمج بلا ماحذف

🟣 نسخة احتياطية Appwrite (ضمانة خامسة)

إعداداتها فالكود (Endpoint/Project/Database/Collection) — مرة وحدة، بعدها كتخدم وحدها بلا تدخل
صيفط نسخة دابا لـ Appwrite
رجّع آخر نسخة من Appwrite — كيدمج بلا ماحذف
حمّل الملف مباشرة من Appwrite للهاتف (بلا دمج فالتطبيق)

📨 نسخة احتياطية عبر Telegram (بلا Gmail خالص)

دير بوت من @BotFather فتليغرام، خد التوكن ديالو، صيفط ليه رسالة، وزور api.telegram.org/bot<TOKEN>/getUpdates باش تلقى chat id ديالك
📊 صيفط التقرير الموحد دابا إلى Telegram — ملف حي واحد فقط
📊 تقرير مقروء (جدول: الاسم، يوم الالتحاق، الأشهر) — ملف واحد بيتبدل تلقائيا مع كل تعديل
رجّع آخر نسخة من Telegram — أوتوماتيك، كيدمج بلا حذف
حمّل الملف مباشرة من Telegram للهاتف (بلا دمج فالتطبيق)

🟢 نسخة احتياطية عبر WhatsApp (Green API)

استخدم Green API (خطة المطورين المجانية). سجل فـ green-api.com، سكان الكود، وخد ID Instance و Token.
📊 صيفط التقرير الموحد دابا إلى WhatsApp — ملف حي واحد فقط
📋 قالب جاهز باش تزيد طالب مباشرة من واتساب — كيبقى لاصق فالمحادثة

🐙 نسخة احتياطية عبر GitHub

دير Personal Access Token من GitHub (صلاحية Contents: Read/Write على ريبو خاص بيك)، وحط اسم الريبو بصيغة owner/repo. الملفات كيتسجلو فمجلد خاص بيك (باسم المعرف ديالك) باش ما يتخلطوش مع معلمات آخرين.
صيفط نسخة دابا لـ GitHub
رجّع آخر نسخة من GitHub — كيدمج بلا حذف
حمّل الملف مباشرة من GitHub للهاتف (بلا دمج فالتطبيق)
نزّل تقرير "تقرير الطلبة" من GitHub للهاتف

📦 نسخة احتياطية عبر Dropbox

دخل لـ dropbox.com/developers/apps ← دير App ← فقسم "Generated access token" دوس Generate باش توليد توكن دائم، والصقو تحت
صيفط نسخة دابا لـ Dropbox
رجّع آخر نسخة من Dropbox — كيدمج بلا حذف
حمّل الملف مباشرة من Dropbox للهاتف (بلا دمج فالتطبيق)
