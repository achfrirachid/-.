🔥 تسجيل الدخول بـ Google (اختياري — Drive و Sheet غير)

ماداخلش بعد (ماشي ضروري)
Firebase و Supabase و Telegram خدامين بلا هاد الزر خالص. الزر هادا خاصك بيه غير إيلا بغيتي زيادة Google Drive و Google Sheet (هادوك زوج وحدين لي محتاجين Google بحكم القانون ديال Google نفسها)
رجّع البيانات ديالك من Firebase — بلا Gmail، خدام دائما بمساحة موحدة
استرجاع شامل: كيجمع فنفس الوقت من Firebase + Supabase + Drive + Sheet
صيفط نسخة دابا لـ Firebase

👩‍🏫 بيانات المعلمات (أدمين فقط)

كل معلمة دخلت بجيميلها الخاص بياناتها معزولة، وكتبان ليك هنا باش تسترجعها ولا تصدرها بلا ما تختلط مع بياناتك

🩺 تشخيص حي — تأكد الأربعة خدامين فعلا

كيدير كتابة وقراءة اختبار حقيقية فكل مصدر (بلا ما يمس البيانات ديالك) ويعطيك ✅ ولا ❌ بالسبب الدقيق

☁️ المزامنة مع Google Drive (نسخة احتياطية)

ربط الحساب يدويا (اختياري — كيتربط وحدو مع تسجيل الدخول فوق)
رجّع آخر نسخة من Drive (بعد تثبيت جديد) — كيدمج بلا ماحذف
صيفط نسخة دابا لـ Drive

🟢 نسخة احتياطية Supabase (ضمانة رابعة)

خاصك تكون داخل بـ Google (فقسم Firebase فوق) — كل حساب عندو بياناته الخاصة، بلا تخلط مع حتى واحد
صيفط نسخة دابا لـ Supabase
رجّع آخر نسخة من Supabase — كيدمج بلا ماحذف

📨 نسخة احتياطية عبر Telegram (بلا Gmail خالص)

دير بوت من @BotFather فتليغرام، خد التوكن ديالو، صيفط ليه رسالة، وزور api.telegram.org/bot<TOKEN>/getUpdates باش تلقى chat id ديالك
صيفط نسخة دابا لـ Telegram (فالشات ديال البوت)
رجّع آخر نسخة من Telegram — أوتوماتيك، كيدمج بلا حذف

🐙 نسخة احتياطية عبر GitHub

دير Personal Access Token من GitHub (صلاحية Contents: Read/Write على ريبو خاص بيك)، وحط اسم الريبو بصيغة owner/repo
صيفط نسخة دابا لـ GitHub
رجّع آخر نسخة من GitHub — كيدمج بلا حذف

📊 Google Sheet (تلقائي، بلا ما تكتب حتى كود)

ربط الحساب — أول مرة كيخلق ليك شيت وحدو فـ Google Drive ديالك
المزامنة التلقائية — كل مرة تسجل، تبدل، ولا تمحي شي حاجة، كتتصيفط وحدها للشيت
حل الشيت ديالك وشوفو بعينيك
صيفط نسخة دابا
رجّع البيانات من الشيت (بعد تثبيت التطبيق من جديد) — كيدمج بلا ماحذف
